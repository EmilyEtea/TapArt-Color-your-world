# TapArt 

A kid-friendly digital coloring web app built with **Flutter** and **Dart**, designed to run in the browser.

**by: Emily Etea**

---

## What It Does

TapArt lets children pick a coloring template and fill it with colors using a tap-to-fill interaction — just like the paint bucket tool in MS Paint. No downloads, no setup, just open the browser and start coloring.

---

## Features

- **User authentication** — register and sign in with email and password via Firebase Auth; each account has its own gallery
- **Tap-to-fill coloring** — flood-fill algorithm fills enclosed regions instantly; outline pixels are never overwritten
- **Two templates** — Butterfly 🦋 and House 🏠, each with many distinct regions for coloring
- **19-color palette** — soft, kid-friendly colors with hover name labels
- **Custom color picker** — HSV sliders to mix any color beyond the preset swatches
- **Zoom slider** — 40%–150% zoom for detail work or full-picture view
- **Undo** — steps back up to 20 fill actions
- **Reset canvas** — restores the original blank template instantly
- **Save / Download** — exports the finished artwork as a PNG to the browser's Downloads folder
- **Gallery** — view and delete all saved artworks, stored locally per user account

## Setup

### 1. Install dependencies
```bash
flutter pub get
```

### 2. Configure Firebase
```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

Then in [Firebase Console](https://console.firebase.google.com):
- **Authentication** → Sign-in method → enable **Email/Password**

### 3. Run
```bash
flutter run -d chrome
# or
flutter run -d edge
```

| Field | Rule |
|---|---|
| Name | Max 10 characters |
| Password | 6–12 characters, letters and numbers only (no special characters) |

## Notes

- Artwork metadata is stored in browser local storage (SharedPreferences) per user UID — no cloud database required
- The app requires internet only for Firebase Authentication (login/register); coloring and gallery work offline once logged in
